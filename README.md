# يوميات — Yawmiyat

تطبيق ويب عربي (RTL) مبني باستخدام Python وFlask. هذه النسخة **هيكل أولي** وليست نظام إدارة متكاملًا جاهزًا للاستخدام المؤسسي.

## حالة الوظائف
- **موجودة:** التسجيل المحلي، تسجيل الدخول والخروج، تخزين كلمات المرور على شكل hash، لوحة تحكم أولية، مخطط SQLAlchemy، حماية CSRF، بعض ترويسات الأمان، وتحديد معدل لمحاولات التسجيل والدخول.
- **غير مكتملة:** واجهات وإجراءات CRUD لإدارة الشركات والموظفين والمهام والجداول والمرفقات، صلاحيات إدارة الشركات والأدوار، تخزين المرفقات الفعلي، استعادة كلمة المرور، والتحقق من البريد الإلكتروني.
- **غير مفعلة:** تسجيل Google والدفع الإلكتروني. لا يوجد إعداد أو تحقق نشر على Netrun في هذا المستودع.

## المتطلبات والتشغيل المحلي

يتطلب Python 3.10 أو أحدث وpip. استخدم بيئة افتراضية لتجنب تعديل Python الخاص بالنظام.

### Windows PowerShell
```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:SECRET_KEY = python -c "import secrets; print(secrets.token_hex(32))"
$env:APP_ENV = "development"
$env:COOKIE_SECURE = "0"
$env:AUTO_CREATE_DB = "1"
python app.py
```

### Linux/macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export SECRET_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
export APP_ENV=development
export COOKIE_SECURE=0
export AUTO_CREATE_DB=1
python app.py
```

افتح `http://127.0.0.1:5000`.

## إعداد قاعدة البيانات

- إذا لم يُضبط `DATABASE_URL`، يبقى المسار الافتراضي كما هو: SQLite في `instance/yawmiyat.db`.
- لتشغيل الاختبارات، تضبط كل fixture عنوان SQLite إلى ملف مؤقت داخل `tmp_path`، ثم تنظف قاعدة الاختبار المؤقتة. سير CI لا يمرر `DATABASE_URL`.
- `AUTO_CREATE_DB=1` ينشئ الجداول الناقصة فقط عند التشغيل المباشر. `db.create_all()` ليس نظام ترحيلات ولا يحدّث مخطط قاعدة موجودة.
- لا تغيّر `DATABASE_URL` في بيئة قائمة قبل التحقق من العنوان والنسخ الاحتياطي وخطة الترحيل. لا تستخدم قاعدة بيانات الإنتاج للاختبار. لا يتضمن هذا المستودع ترحيلات مخطط حاليًا.

## الأمان وإعداد الإنتاج

- عيّن `APP_ENV=production` في بيئة الإنتاج. عندها يرفض التطبيق البدء إذا كان `SECRET_KEY` مفقودًا أو أقصر من 32 حرفًا أو قيمة placeholder، ويرفض البدء إذا لم يكن `COOKIE_SECURE=1`.
- أنشئ `SECRET_KEY` عشوائيًا وثابتًا عبر مدير أسرار المنصة أو مولّد آمن، واحفظه كمتغير بيئة/سر في منصة الاستضافة فقط. لا تضعه في Git أو السجلات، ولا تغيّره بين عمليات إعادة التشغيل.
- لا تضبط `COOKIE_SECURE=1` إلا بعد التأكد من أن HTTPS مفعل فعليًا لكل حركة المرور إلى التطبيق. إعداد HSTS متروك لطبقة النشر بعد التحقق من HTTPS؛ التطبيق لا يرسل HSTS تلقائيًا.
- حماية الجلسة: `HttpOnly` و`SameSite=Lax`، وتدوير رمز CSRF عند نجاح تسجيل الدخول/التسجيل والخروج، والتحقق من CSRF على طلبات التغيير، وترويسة CSP أساسية وترويسات أمان إضافية.
- حدود المعدل الافتراضية: 5 محاولات تسجيل دخول لكل عنوان IP خلال 15 دقيقة، و5 طلبات تسجيل لكل عنوان IP خلال ساعة. تُرجع الطلبات الزائدة HTTP 429 و`Retry-After`.
- **قيد مهم:** محدد المعدل مخزّن في ذاكرة عملية Python الحالية. لا يتشارك العدّاد بين عدة workers أو نسخ، ويُعاد ضبطه عند إعادة التشغيل؛ لذلك يجب استخدام محدد معدل على مستوى الـ reverse proxy/بوابة الاستضافة أو مخزن مشترك قبل نشر عام متعدد العمليات. لا تثق في `X-Forwarded-For` ما لم تضبط الوكيل الموثوق بعناية.
- التسجيل العام ينشئ دور `employee` فقط؛ لا توجد آلية عامة لمنح دور مدير. لوحة التحكم لا تعرض مهام كل النظام للمدير، بل تقيد العرض بمهام الشركة المرتبطة بالمستخدم أو المهام التي أنشأها/أُسندت إليه إن لم يكن مرتبطًا بشركة.
- لا توجد حاليًا واجهات CRUD مكتملة لإدارة الشركات والموظفين والمهام والجداول والمرفقات، ولا تخزين فعلي آمن للمرفقات. لا تعتبر هذه الوظائف جاهزة للإنتاج.
- لا توجد كلمات مرور حقيقية أو مفاتيح API في ملفات المثال. `.env.example` يحتوي قيمًا إرشادية فقط.

## الاختبارات

```bash
python -m pytest -q
```

الاختبارات تستخدم قاعدة SQLite مؤقتة معزولة لكل fixture، وتغطي المصادقة وCSRF والجلسات وترويسات الأمان وحدود المعدل وإعدادات الإنتاج وعزل المهام. نجاح الاختبارات لا يثبت سلامة إعداد قاعدة بيانات الإنتاج أو جاهزية التطبيق للنشر.

## النشر

لا تنشر هذه النسخة مباشرة على Netrun أو أي بيئة إنتاج. قبل النشر، أكمل وظائف الإدارة، أضف ترحيلات قاعدة بيانات وخطة نسخ احتياطي واستعادة، اختبر صلاحيات كل مسار وملكية الموارد، أضف محدد معدل مشتركًا، واختبر إعداد HTTPS وبيئة staging. يجب أن يكون `DATABASE_URL` في أي بيئة جديدة عنوان قاعدة مستقلة مخصصة لهذا التطبيق بعد التحقق منه صراحةً.
